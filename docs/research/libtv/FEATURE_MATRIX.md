# LibTV 功能覆盖矩阵

用途：把“存在某个入口”和“完整复刻了该能力”分开。每项必须达到当前站内 UI、官方契约、状态/错误和复刻设计四类证据中的合理组合，才能标为完成。

状态：

- `OBSERVED`：当前站内真实 UI、交互或网络行为直接可见；登录态另行注明。
- `OFFICIAL`：官方指南、CLI 或官方源码已确认。
- `PARTIAL`：只有部分状态或旧版证据。
- `PENDING`：尚未验证。
- `COST_GATED`：需要真实生成、积分或付费，未获单独授权。
