# 素材驱动编辑流程

## 入口证据

- 首页附件支持本地上传或从资产库选择。
- 画布可添加图片、视频、音频、资产库和脚本等节点。
- 生成历史提供图片/视频/音频入口，但目前只归档空态。
- 官方指南覆盖图片编辑、视频剪辑/合成/分离、音频截取/变速、角色/主体库。

当前登录态还直接确认：

- 已生成图片详情提供全景、多角度、打光、裁剪/旋转、九宫格、人像和情绪工具。
- 九宫格与人像工具先创建引用原图的待确认节点；只有用户再次执行才进入付费生成。
- 情绪工具先做人像识别/手动框选，再选择情绪坐标、分辨率和数量。
- 多张已有图片可先组成普通组，再转为分镜组；2K 拼接每次点击立即创建新图片节点。
- 已生成视频详情可配置参考、提示词、特效、运镜和输出规格；“剪辑”进入独立时间线，
  空时间线不会自动带入当前视频，也不能导出。

## 目标闭环

1. 选择本地文件或已有 Asset；本地文件先进入 staging upload。
2. 校验大小、MIME、解码、恶意内容、owner/workspace 和人像/音色/版权策略。
3. 通过后登记 COMMITTED Asset，并在画布创建资源节点或填入现有节点。
4. 用户选择非破坏工具：图片区域/焦点/镜头、视频剪辑/合成/分离、音频截取/
   变速等；原 Asset 不覆盖。
5. 工具参数与输入 Asset version 冻结到 ExecutionSpec，生成新的 Job/Artifact。
6. Artifact 成功提交后登记新 Asset、写回节点 output 和 workflow revision。
7. 用户可从生成历史重新引用结果；删除/撤销遵守引用、公开快照和合法保留规则。

## 需要逐项截图的状态

- 上传选择、进度、取消、格式/大小错误、网络中断、重复内容和成功。
- 资产库有内容时的搜索、筛选、排序、批量、预览、下载、移动、删除和恢复。
- 每个图片/视频/音频工具的参数、预览、确认、排队、成功、失败和取消。
- 角色、视频主体、风格、音色的创建、引用、权限、审核、编辑和删除。
- 合规检查中、通过、驳回、过期、撤销以及对缓存/发布/克隆的反向影响。
- 结果版本、原始素材回溯、跨 workspace 分享和无权限引用。
