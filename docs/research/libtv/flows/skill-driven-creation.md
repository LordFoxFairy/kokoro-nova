# Skill 驱动创作流程

## 已观察部分

1. 从 Skill 市场按分类浏览，或在首页选择器即时搜索；搜索结果和空态均已截图。
2. 打开 Skill 详情，查看作者、分类、使用/收藏统计、示例和使用摘要。
3. “选角Casting”详情的 13 节结构化可执行规范已连续截图，覆盖输入、调用、
   资产引用、确认门、降级、输出与故障排查。
4. 详情提供收藏、分享和“添加 Skill”动作。
5. 未登录可先将通用 Skill 加入 composer；收藏、我的和创建要求登录。
6. 仅有 Skill chip 时发送按钮会启用；提交后进入认证层并保留已选 intent。

## 目标执行链路

以下是由入口、官方 Skill/OpenAPI/CLI 和复刻目标推导的验收流程，不是已完成的
站内观察：

1. 选择固定 `skillId + version` 并加入 AgentSession。
2. 根据规范检查缺失输入、素材、模型 entitlement 和工具权限。
3. GA 生成 plan；涉及画布 mutation、外部发送或积分消耗时进入确认门。
4. 通过同一 domain command 层创建节点/分组/连线和 GenerationJob。
5. 进度、结果、降级和错误写回 session，并把 Artifact 登记到项目资产。
6. Skill 更新不改变运行中的 ExecutionSpec；新会话显式选择新版本。

## 待采集状态

- 市场分类切换、我的已有项。
- 添加中、重复添加、移除、权限不足和版本不可用。
- 输入补全、计划确认、拒绝/修改、执行、部分失败和继续运行。
- Skill 创建、编辑、草稿、版本、测试、审核、发布、下架和删除。
