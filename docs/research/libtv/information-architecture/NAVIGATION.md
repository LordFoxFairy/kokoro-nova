# LibTV 导航规则

## 原则

采用对象优先结构：稳定入口指向用户长期识别的“地方”，创建、复制、生成、
分享和发布保持为上下文动作。视觉位置仍以 LibTV 实际界面为复刻基准；本文件
约束语义与状态，不擅自改变已观察标签。

## 全局层

| 地方 | 可见范围 | 职责 | 已观察入口 |
| --- | --- | --- | --- |
| 首页 | 公开/登录 | 发现、自然语言输入、快捷启动 | Logo/返回首页 |
| Skill | 公开/登录 | 浏览、搜索、收藏和选择能力 | 首页 Skill 入口/选择器 |
| TV Show | 公开 | 浏览公开作品及制作过程 | 首页内容流 |
| 项目 | 登录 | 当前 workspace 的创作对象 | 开始创作、项目页 |
| Agent | 登录 | 新会话、历史与跨项目协作 | Agent 入口/画布侧栏 |
| 账户菜单 | 登录 | 身份、团队、会员、积分、存储、设置、CLI | 头像菜单 |

活动、挑战赛、帮助、会员促销和积分余额属于快捷入口或状态，不应被建模成
与项目/Agent 同级的核心内容对象。

“开通会员”和“会员超市”虽然相邻但不能合并：前者管理个人/团队订阅，后者
购买模型专享积分并设置余额池消耗顺序。登录购买后都回到统一的购买记录、
积分明细和发票信息架构。

头像菜单中的积分余额、资产、个人中心和订阅/开票会在新标签打开 `liblib.art`
共享账户域；关闭新页后原 LibTV 页面和滚动位置保持不变。复刻可使用同域 SSO 或
短期授权跳转，但必须保持 tenant scope，不能把 Cookie 直接暴露给外部 Agent。

## 局部层

### Project / Canvas

- 顶层上下文：返回、项目名称、画布切换/新建、分享和更多操作。
- 主视图：`工作流` 与 `故事板` 使用分段切换，同一时刻只激活一个。
- 左侧工具：节点创建、素材/角色、历史、工具箱与帮助按现有图标顺序保留。
- 右侧上下文：Agent 会话不改变项目归属，选中节点会以 context chip 注入会话。
- 节点级动作仅在选中节点后显示；危险动作进入更多菜单并要求明确反馈。

### Agent

- 会话级：新建、历史、分享、设置和 CLI。
- 输入级：附件、模型、Skill、`@` 引用、手动/自动生成模式。
- 执行级：计划、工具调用、确认、进度、取消、重试和结果回链，待真实任务补证。
- 独立 Agent 页与画布侧栏使用同一命名，不创建“聊天/助理/Agent”近义词分裂。

### Skill

- 集合筛选：全部、通用、收藏、我的及站内实际分类。
- 详情顺序：身份/作者 -> 能力说明 -> 使用示例 -> 可执行规范 -> 使用动作。
- “收藏”只改变个人集合；“添加到会话/使用”才改变当前 Agent 上下文。

### TV Show

- 目录使用分类和搜索；详情保留返回目录与相邻作品带。
- 详情主动作是观看，次动作是查看制作过程；复制项目只在只读制作过程内出现。
- 工作流/故事板是只读本地切换，不改变详情 URL 的公开对象身份。
- 未登录复制时保持用户当前位置，并叠加登录层；成功登录后恢复原命令意图。

### 账户与共享资产

- 账户菜单是全局状态摘要，不承载完整账本、订单、资产和作者内容管理。
- 积分明细按获取/消耗/返还组织，余额池只是账本投影；任务 ID 负责关联生成任务。
- 订阅计划与购买记录同属交易页，发票从可开票订单动作发起。
- 资产按 Lib 生成器、LibTV、ComfyUI、WebUI 和 AI 应用来源筛选，共享对象身份。
- 个人中心按发布/点赞和模型、工作流、图片、视频、LibTV 类型组织公开内容。

## 权限与状态

- 未登录：可见首页、Skill 公开内容、TV Show、作品详情和公开制作过程。
- 已登录个人：增加私有项目、Agent、资产、收藏、复制和账户设置。
- 团队成员：导航只展示有权访问的 workspace/项目；搜索不能泄漏不可见对象。
- 计费/合规门槛在动作发生前解释原因，不把整个页面误显示为空态。
- 公开快照被下架或资源失效时提供明确不可用状态和返回路径。

## URL 与返回行为

- 对象 URL 使用稳定 ID；可读标题只作可选 slug，不作为权限或查找主键。
- 弹层/抽屉关闭后回到触发时的同一滚动位置和筛选状态。
- 登录重定向应携带安全的 intent 标识，成功后恢复复制/创建动作，不携带密钥。
- 项目列表已确认为 `/project`；画布使用带 `spaceId/projectId` 的 `/canvas` 查询路由。
- 会话和公开快照的精确稳定路由仍待登录态网络证据确认。

## 词汇规则

- 地方用名词：项目、画布、资产、Skill、Agent、TV Show。
- 按钮用动作：开始创作、添加到会话、复制项目、查看制作过程。
- 固定使用“生成历史”描述资产结果列表，保留“版本历史”给 workflow revision。
- 固定使用“工作流”描述依赖图，“故事板”描述叙事/媒体投影。
- `Workspace` 在官方 CLI 已使用；中文 Web 最终标签需以登录态管理页为准。
