### 对本地 mock 与后端契约的新增约束

1. `ScriptV2Run` 除执行进度外还应保留每个镜头的阶段完成度，批量动作以缺失前置条件返回
   明确的 disabled/validation projection，而不是把按钮可用性仅留给组件猜测。
2. 镜头行字段应是同一 `WorkflowDocument` 中 Script V2 node 的可编辑 projection；确认镜头后的
   资产准备和提示词合成继续引用同一稳定镜头 ID，避免为故事板创建第二套草稿。
3. `next`、批量分镜、批量生视频与下载都必须有可重放的 local mock 成功、缺前置条件和失败/重试
   场景；`Escape` 只关闭该面板，不丢弃未保存的页面草稿。
4. 1440×900 基线需要同时覆盖“确认镜头”可编辑态与至少一个后续阶段的批量动作可用态，避免只用
   静态表格截图证明能力。
