# Script V2 画布可访问性契约（2026-09-05）

- **来源**：用户已有登录会话中的 `https://www.liblib.tv/canvas?spaceId=…&projectId=…`。
- **方法**：仅读取加载完成后的浏览器可访问性树；未点按、编辑、生成、下载、发布、上传或改变线上项目。
- **证据等级**：**直接可见登录态 UI**。本记录不保留项目 ID、项目名、素材名、用户标识、余额、Cookie、Token、提示词或其他项目内容。

## 镜头面板语义

当前展开的 Script V2 面板包含：

- 三个阶段按钮与 `关闭 (ESC)`；关闭是局部面板收拢动作。
- 表格列为：镜号、时长、画面描述、景别、光影氛围、对白·旁白、音效、运镜、最终提示词、操作。
- 行首暴露“拖拽调整顺序”的辅助说明；时长、画面描述、光影/对白/音效/运镜等字段以可编辑 button、text field 或 pop-up button 形式呈现。
- `最终提示词` 与 `行操作` 是显式按钮；底部有 `添加镜头` 与“下一步：准备资产”推进动作。

这证明本地 Script V2 mock 至少应把**阶段、镜头行、可编辑字段、排序、局部关闭、下一步 gate 与批量
gate**建模为同一运行状态的投影。它不证明任何真实 API 字段、网络 URL、生成语义、收费规则、异步
状态或付费路径。

## 使用规则

1. 仅将本记录用于布局、辅助名称、控件层级和 disabled/阶段语义的高保真复刻。
2. 未观察到的真实接口、字段、项目内容或异步任务必须继续以本地 fixture/OpenAPI 交接契约表示，并显式标记为 local-only。
3. 未来若取得有效镜头、资产完成或提示词完成态的只读 UI 证据，可在此基础上补充对应状态；不能以本地成功 E2E 代替官网事实。
