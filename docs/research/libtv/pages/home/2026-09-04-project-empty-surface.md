## 当前可见结构

1. `返回`；
2. `全部项目`；
3. 搜索文本框；
4. `回收站` 按钮；
5. `新建文件夹` 按钮；
6. 空态的 `开始创作` 和 `创建新的视频项目` 文案。

可访问性树没有把 `回收站` 或 `新建文件夹` 标为 disabled。空项目空间仍保留这两个
二级动作，与“开始创作”一起提供完整的空态操作面。

## Kokoro Nova 交接约束

- `authenticated-empty → /project` 必须渲染 `还没有项目` 空态及开始入口；
- `回收站` 和 `新建文件夹` 在空态保持 enabled，不能因为列表为空而伪造 disabled 状态；
- toolbar 顺序保持 `返回 → 全部项目 → 搜索 → 回收站 → 新建文件夹`，以便未来后端替换时
  不改变桌面布局和键盘路径。
