# 2026-09-04 官网公开首页表面复核

- 来源：`https://www.liblib.tv/`，浏览器可访问性树
- 复核时间：2026-09-04
- 会话边界：仅观察已加载首页；未点击“新建项目”、画布创建、模型生成或任何会写入账户状态的动作
- 证据等级：**直接可见 UI**。此记录只描述页面结构和可访问名称，不把界面文案推断为后端字段或真实 API schema。

## 首屏可见层级

1. **活动条**：倒计时、促销正文与关闭按钮。当前正文以 Seedance 2.5 720P 年会员促销为主题，说明活动内容和倒计时必须来自独立营销配置，而不是创作页面常量。
2. **侧边导航**：首页、收起侧栏、新建项目、项目、LibTV Agent、创作者挑战赛与帮助。其中“新建项目”是主导航之外的高强调动作。
3. **快捷创作区**：
   - 新建画布创作；
   - Seedance 2.5：多参创作、音视频直出 30s；
   - Wan 3.0：改写视频画面、剧情、环境；
   - Minimax H3 Max：极速生成；
   - 导演台：3D 虚拟场景、空间控制；
   - 逐帧拉片：传视频、逐帧拉片快捷参考；
   - 片段重拍：精准修改视频片段。
4. **LibTV Agent 入口**：添加附件按钮、禁用的发送按钮和“全部 Skill”入口。空输入时禁止发送是当前明确的可见交互契约。
5. **TV Show 入口**：标题、`向左滚动` / `向右滚动` 分类轨、搜索输入和搜索按钮，内容以列表承载；部分作品的“查看创作过程”会显示 disabled。

## 可复刻约束

- 快捷入口需要有标题、能力摘要和独立激活动作；当前产品的模型名与促销文案会变动，Kokoro Nova 继续由本地 fixture 驱动而不把本次名称变成协议枚举。
- 首页保持“公开发现 + 私有创作入口”并置：TV Show 搜索可见，而项目创建/画布进入属于独立动作。
- TV Show 分类是可横向移动的轨道，不应被实现成会改变 checkbox 语义的筛选器；两侧滚动控制需在窄屏保留。
- 可访问名称应保留为稳定 E2E 锚点：`新建项目`、`新建画布创作`、`添加附件`、`全部Skill`、`搜索`、`关闭`。
- 该观察补充而不覆盖 2026-09-03 的 1440×900 截图测量；本次采集没有保存图片像素基线，不能用于像素级差异判断。
