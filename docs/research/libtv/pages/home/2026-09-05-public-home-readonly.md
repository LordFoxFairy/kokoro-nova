# 2026-09-05 官网公开首页只读复核

- 来源：`https://www.liblib.tv/`，应用内浏览器的可访问性树。
- 会话边界：仅加载首页并读取已渲染结构；未点击新建、登录、生成、收藏、搜索、发布或账户动作。
- 证据等级：**直接可见公开 UI**。本记录不采集 Cookie、token、用户资料、项目 ID、网络 payload 或私有素材。

## 本次直接可见的当前结构

1. 顶部活动条有倒计时、促销正文和单独的`关闭`按钮；促销文案仍围绕 Seedance 2.5 年会员，但
   剩余时间是动态值，不能写入稳定 fixture 协议。
2. 侧栏动作依次为`首页`、`收起侧边栏`、`新建项目`、`项目`、`LibTV Agent`、`创作者挑战赛`
   与`帮助`。`新建项目`独立于普通导航，继续作为高强调私有创作入口。
3. 当前快捷创作卡可见 7 项：`新建画布创作`、Seedance 2.5、Wan 3.0、Minimax H3 Max、导演台、
   逐帧拉片、片段重拍；每张模型/工具卡将名称、短标签和能力摘要暴露为同一个可访问按钮名称。
4. `LibTV Agent` 区在空输入时保留`添加附件`和 disabled `发送`，并有`全部Skill`入口。
5. `TV Show`区域当前直接可见标题、`全部`范围文案、可输入搜索框和`搜索`按钮；内容区在本次
   只读采样时为一个列表容器，未滚动、搜索或打开作品。

## 路由与事实边界

本次浏览器将手工猜测的 `https://www.liblib.tv/showcase` 返回为官网 `404 Not Found`。因此
Kokoro Nova 的 `/showcase` 是本地演示信息架构，不得将它倒推为官网公开 TV Show 的真实 URL 或
真实后端 API。官网当前可见的`创作者挑战赛`是一个 UI 名称；任何 URL、请求方法或 schema 都应
只在实际请求/明确导航证据出现后记录。

## 对本地复刻的保持项

- 快捷卡、营销活动、TV Show 和 Agent 必须保持各自的 fixture/projection，不让营销倒计时或当日
  模型名称污染长期 API 枚举。
- 首页 anonymous 状态保留空输入 disabled、公开发现读取与私有新建登录门的边界。
- 对应的本地 `/showcase` 路由应在文档中始终标为 frontend-only 演示路径；未来 backend adapter
  只能依据 OpenAPI `operationId` 和已记录的官网请求证据接入。

## 补充：公开 TV Show 卡片的索引证据

公开搜索索引（同一 `https://www.liblib.tv/` 首页，采集时间为近月）在内容列表中暴露了作品标题、
创作者显示名与`先锋 / 专业 / 荣誉`等展示标签，并在列表末尾显示“没有更多了”。这属于**公开索引
摘要**，低于上面的实时可访问性树证据：

- 它可确认 TV Show 不是只有搜索框的空壳，卡片至少包含作品、作者、等级标签与有穷列表终点；
- 它不能证明这些字段的真实 API 名称、分页 cursor、授权要求、作品详情路由或媒体地址；
- 本地 fixture 可保持 `title / creator / displayBadge / terminal-page` 这一展示投影，但必须继续把
  `snapshotId`、分页和冻结工作流放在本地 OpenAPI 与 mock 契约中，不能从搜索索引推导出上游 wire schema。
