## 几何对照

| 区域 | 官网约束 | 本地实测/断言 | 结果 |
|---|---:|---:|---|
| 活动条 | `(8, 8, 1424, 48)` | `(8, 8, 1424, 48)` | 对齐 |
| 应用主体顶边 | `y=64` | `y=64` | 对齐 |
| 展开侧栏 | `x=8, w≈232` | `x=8, w=232`，容差 `±2px` | 对齐 |
| 展开内容起点 | `x≈240` | `x=240`，容差 `±2px` | 对齐 |
| 收起侧栏/内容起点 | `x=0, w≈68` | `x=0, w=68`，容差 `±2px` | 对齐 |
| 首页 Banner | `(280, 114, 1120, 140)` | 四项均以 `±4px` 断言 | 对齐 |
| 快捷创作区 | `x≈280, y≈278, h≈200` | `y` 容差 `±8px`，`h` 容差 `±2px` | 对齐 |
| 最近项目 | 三张约 `272×90` 横卡 | 固定 `max-width: 838px`、三列、`10px` 间距 | 对齐 |
| 项目页展开卡 | `x≈280, w≈212, h≈120` 封面 | `x` 容差 `±4px`、列宽约 `214px`、封面 `120px` | 对齐 |
| 项目页收起卡 | `x≈108, w≈247` | `x=108`、宽 `244..252px` | 对齐 |

侧栏切换改变网格可用宽度，不覆盖内容；展开状态项目区使用可用宽度的 `80%`，因此与官网一样在收起后将四列从约 `212px` 放大到约 `247px`。

## 交互对照

- 主导航根据路由设置 `aria-current`；侧栏可由键盘触发，状态写入 `libtv.sidebar.collapsed` 并在刷新后恢复。
- 首页空画布、六个创作工具和 Agent 有效草稿都会创建项目；工具入口把稳定 intent 写入 `brief`。
- Skill 点击只改变当前输入上下文，不提前生成或扣费；空草稿发送保持禁用。
- TV Show 分类和搜索在本地 fixture 上即时过滤；六张封面均来自 `/fixtures/libtv/showcase/`。
- 项目搜索不发网络请求；回收站展示确定性空态；文件夹保持“立即创建未命名文件夹”的官网行为。
- 项目/文件夹菜单、重命名、复制、移动和强确认删除沿用原有 API 与稳定测试 ID。

## 已知且有意保留的 fixture 差异

| 差异 | 处理 |
|---|---|
| 官网顶部倒计时持续变化 | 本地冻结为确定性文本，避免视觉基线随时间漂移。 |
| 官网截图账户积分为当时实时值 | 本地显示 scenario 账本余额，确保生成、预留和返还测试一致。 |
| 官网最近项目包含账户私有封面 | 本地空项目保留占位图，其余使用已登记的公开 LibTV 封面；不把私有媒体写入仓库。 |
| 部分官网图标与字形来自闭源字体/图标包 | 本地使用同尺寸 SVG 与系统中文字体，几何和交互命中区保持一致。 |

以上差异不改变信息架构、布局、可达动作或 API 契约。画布、节点、故事板和 Video 编辑器差异继续进入下一批，不计入本页完成结论。
