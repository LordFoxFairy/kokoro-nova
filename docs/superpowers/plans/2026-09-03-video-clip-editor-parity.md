# Video 合成器、时间线与导出实施计划

> 本计划是 LibTV 全能力复刻总目标中的一个可验证里程碑；完成本计划不代表总目标完成。

## 目标

依据官网故事板中已经实测并留档的视频合成界面，把现有弹窗式 Clip Editor 改为故事板内嵌编辑工作区，并补齐可持久化、可预览、可导出的时间线交互：

- 左侧故事板素材区保持可见，视频合成器占据右侧工作区；
- 标题、导出菜单、关闭动作、预览区和底部时间线按官网层级与几何关系重建；
- 空时间线保持真实空态，裁切、分割、删除、变速和导出均有正确门槛；
- 转场工具提供官网已观察到的 `淡入淡出 / 黑场过渡 / 白场过渡` 三项及属性面板；
- 字幕工具提供 `字幕 / 文本`、搜索、新建、显隐和时间线轨道；
- 片段支持添加、选择、裁切、分割、变速、重排、删除，时间轴支持播放头、缩放和适配；
- 编辑文档写入 `videoComposite` 节点，不以组件临时状态作为唯一事实来源；
- `POST /api/compose` 请求/响应、错误和 OpenAPI schema 与真实本地实现严格一致；
- 使用领域测试、契约测试、Playwright 流程和 `1440×900` 视觉基线验收。

所有视频、海报和测试数据只使用仓库内 fixture 或本地合成产物，不把登录账号中的私有媒体固化到运行时。

## 官网事实基线

- 视频合成是故事板内嵌工作区，不是居中的 modal；
- 左侧故事板素材列保留，编辑器标题为“视频合成”，右上角为“导出”下拉和关闭按钮；
- 底部时间线是独立浮起面板，上方工具栏含裁切/分割、字幕、转场、当前时间、播放、总时长、全屏/复位、缩放和适配；
- 空时间线不会自动加入当前媒体，导出菜单中的“导出到本地 / 导出到画布”均禁用；
- 转场库和转场属性为并列浮层，基础转场为淡入淡出、黑场过渡、白场过渡；
- 字幕面板含“字幕 / 文本”页签、搜索、“新建字幕”和空态“暂无字幕”；
- 字幕工具激活时，时间线出现独立字幕轨道及显隐控制。

## 本地文档模型

`videoComposite.data.extra.composite` 使用版本化文档：

```ts
interface CompositeDocument {
  version: 1
  clips: CompositeClip[]
  subtitles: CompositeSubtitle[]
  playheadSeconds: number
  zoom: number
}
```

其中每个片段保存来源 `artifactId/nodeId`、源媒体信息、`inPoint/outPoint/speed` 和片尾转场；字幕保存文本、起止时间与可见性。读取旧的 `extra.timeline/transitions/subtitles` 时做兼容迁移，下一次编辑写回版本化文档，同时保留 compose API 所需的规范化请求。
