# Video 参考选择、富引用与运镜库高保真实施计划

> 本计划是 LibTV 全能力复刻总目标中的一个可验证里程碑；完成本计划不代表总目标完成。

## 目标

以当前已登录 LibTV 官网 Video 节点为事实来源，在纯前端本地 fixture 中补齐以下闭环：

- “参考”进入独立的画布选择模式，而不是打开素材面板；
- 已连接上游显示“取消选择”，可用节点显示“添加参考”，非法连接给出确定原因；
- 选中/取消会直接增删工作流边，Video 的生成模式与依赖门槛随之实时更新；
- Video 编辑器以编号参考卡展示上游素材，支持 `@` 富引用、预览/定位和移除；
- “标记”进入与官网一致的元素选择模式壳层，并提供可重复的本地局部区域 mock；
- “运镜”使用大尺寸三标签媒体库，覆盖官网当前可见的 23 个运镜、搜索、收藏、我的运镜、选择和 Escape 层级；
- 所有状态持久化到 Canvas 文档，本地 mock API 可读回，不依赖官网运行时资源或私有媒体。

## 官网事实基线

### 参考

- 点击“参考”后，画布顶部出现蓝色浮条“从画布选择参考”；
- 浮条包含“返回节点”和“退出”，普通顶部导航、左侧工具和底部工具条暂时隐藏；
- 已选上游节点覆盖“取消选择”，点击后断开该节点到当前 Video 节点的边；
- Video 编辑器内参考按 `1 / 2 / 3…` 编号，每张卡有 `@` 和移除按钮；
- `@` 在提示词中插入可辨识的素材 token，并打开该来源的预览；来源可进一步定位到画布节点。

### 标记

- 点击“标记”进入“元素选择模式”；
- 顶部蓝色浮条提示“点击图片选择局部元素”，同样提供“返回节点”和“退出”；
- 本地实现以确定性矩形区域作为分割服务 mock，保存来源节点与归一化坐标。

### 运镜

- 运镜库是覆盖画布的大型媒体面板，不是节点内的小型文字菜单；
- 顶部有“运镜广场 / 我的收藏 / 我的运镜”三标签、搜索框和关闭按钮；
- 广场当前可见 23 个运镜：固定镜头、跟随拍摄、盘旋抬升、盘旋下降、镜头上摇、镜头下摇、镜头左摇、镜头右摇、镜头上升、镜头下降、镜头左移、镜头右移、镜头前推、镜头后移、变焦推进、变焦拉远、柯克变焦、环绕拍摄、滚筒旋转、第一视角、无人机、高空航拍、手持拍摄；
- 每项是视觉预览卡，右上角可收藏；选择后写回 Video 节点并关闭库。

## 领域契约与状态

### 图引用

新增 `video-references.ts`，集中提供：

1. 稳定排序的上游引用；
2. 每个画布节点相对目标 Video 的 `selected / selectable / reason`；
3. 参考切换所需的 `addEdge / removeEdge` mutation；
4. 防自连、防环、防不兼容媒体；
5. 参考 token 的类型化标签。

图边仍是生成编译器的唯一输入事实；富引用 token 只是 prompt 编辑元数据，不复制边关系。

### Video 扩展状态

保存在 `NodeData.extra`：

- `videoMentions`: `{ id, nodeId, label, ordinal }[]`，允许同一来源重复引用；
- `cameraMove`: 当前运镜 ID；
- `cameraFavorites`: 收藏运镜 ID 列表；
- `elementMarks`: `{ id, nodeId, x, y, width, height, label }[]`，坐标为 0–1；
- `customCameraMoves`: “我的运镜”的本地 fixture 列表，默认空。

## 验收条件

1. 参考选择的每一次 UI 操作都能通过 Canvas API 读回对应边；
2. 去除/新增引用后，Video 模式依赖立即重新计算；
3. `@` token 与元素标记关闭/重开后仍存在，删除来源引用后无悬挂元数据；
4. 运镜广场恰有 23 个官网当前名称，收藏、搜索、选择均确定可重复；
5. 1440×900 下关键布局与官网观察一致，交互命中区和 Escape 层级有 E2E 保护；
6. `typecheck / lint / unit / build / e2e` 全绿，运行时网络仅访问本地 `/api/*` 与 `/fixtures/*`。
